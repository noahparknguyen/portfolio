# My personal website/portfolio

Take a look -> [noahpn.dev](https://noahpn.dev)

---

Thanks for checking out my site's source code. I tried to keep things as simple as possible, only adding new dependencies if absolutely necessary.

It's a pretty plain static site built with basic HTML and Tailwind, and deployed via Cloudflare.

I kept the JavaScript to a minimum, with a theme toggle at the bottom being the only client-side script. Everything else is built ahead of time to stay lightweight—for example, I write each blog post in Markdown and convert it to HTML using a marked build script.

Nothing in the codebase is particularly complex. If you spot something you'd like to use on your own site, go ahead and grab what you need. Feel free to take inspiration; just don't clone entire pages verbatim. Where's the fun in that?

Anyways, thanks for stopping by.

– Noah
