How my work flows

Software, hardware, everything in between

A little background

I have a basic set of rules and philosophies I like to follow whenever I need to add a new tool to my stack.

Free is king. I'm not against folks trying to make some cash. I just don't like managing subscriptions and services. Especially whenever I take a break or don't use the tool for a while, it feels like I'm just wasting money.

Open source when possible. It's just nice being able to see exactly what you're downloading. Nowadays, I try to avoid cloud services if I can. It's such a great feeling when you download something and actually own it in today's world of SaaS and PaaS.

Don't leave any mess. I like to play around with new software a lot, and installing and uninstalling all these programs tends to make a huge mess, especially when updating leaves multiple versions of the same program on your drive wasting space. Install through package managers; uninstalls should remove everything without a trace.

Software

Package managers

  • Scoop — How I install, update, and remove most of the apps I use. Easy to manage, and keeps the desktop nice and clean.
  • winget — For everything that needs a proper installer.
  • apt — Same reason as Scoop, just for Ubuntu.

Desktop apps

  • Bruno — I love how everything is stored in plain text locally.
  • Zed — My code editor of choice. Very fast, very efficient, very useful with all the built-in features.
  • Obsidian — My main note-taking app. All the plugins make it super customizable.
  • ONLYOFFICE — Needed an alternative to Microsoft 365 and wanted something a bit simpler than LibreOffice.
  • Thorium Reader — Wanted something lighter than Calibre.
  • Firefox — My go-to browser.
  • Kopia — For all my backup needs.
  • 7-Zip — It's free. What more do you need?
  • OpenTabletDriver — Not a huge fan of the official drivers that come with these tablets. OTD is super simple to use and set up.
  • Bitwarden — To handle my passwords and secure notes.
  • Winhance — Helped a ton with the debloating process.
  • Steam — Obviously.

WSL

  • Ubuntu — A gateway Linux OS for a Windows head like me.
  • Zsh — Chosen for its customizability and auto-completion.
  • Starship — For its speed.
  • fzf — Ctrl+R to search my command history.
  • jq — For reading JSON from APIs.
  • Git — Pretty much standard for all developers.

Languages and tools

  • Java: OpenJDK, Maven — My main programming language. Also the first language I've ever learned. You never forget your first.
  • C/C++: GCC, clangd, CMake, GDB — Whenever I have some free time, it's fun to learn.
  • Python: Python 3, uv — Another tool that feels like every developer should know.
  • Rust: rustup — Installed for competitive programming, but I mainly want to use it alongside JavaScript for web development.
  • JavaScript: Node.js, fnm, pnpm — Handles all my web development.
  • PostgreSQL — My preferred DBMS. Pairs nicely with Spring Boot.
  • Spring Boot — My backend framework of choice.

Setup

I used to be a big accessory and peripheral person: three monitors, a huge mechanical keyboard, and all these other gadgets that I thought helped increase efficiency.

Now I barely have anything at my desk. I do all my work on my laptop, which means I can go anywhere I want and work the exact same way. At home, at a cafe, visiting family, I just need my laptop and I'm good to go.

I do have some accessories at my desk, but they don't get a ton of use. I have a monitor if I want to watch something while I work. I have my mouse and keyboard if I have some free time to play some games. I have an old drawing tablet for whenever I like to sketch out notes. And that's pretty much it.
